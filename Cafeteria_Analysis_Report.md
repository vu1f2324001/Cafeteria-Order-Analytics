Cafeteria Order Analytics & Demand Forecasting

Submitted by: Akshada Valkunde
Submission Date: October 1, 2026
Status: Work in Progress

1. Objective

The objective of this challenge is to analyze cafeteria order data across multiple branches and counters, identify meaningful business patterns, and forecast order demand for the next 7 days for a selected branch.

2. Planned Analysis

The analysis will include:

- SQL data import
- Data cleaning and preprocessing
- Exploratory Data Analysis (EDA)
- Branch-wise order analysis
- Time-based order analysis
- Menu/item-level analysis
- Selection of one branch for forecasting
- 7-day order forecasting
- Business insights and recommendations

3. Tools and Technologies

- MySQL
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Statsmodels

4. Current Status

An initial analysis and forecasting structure has been prepared.

The complete SQL dataset is being processed locally because of its large size. Final numerical insights, visualizations, and forecast values will be updated after validation against the complete dataset.

5. Next Steps

1. Complete SQL data import.
2. Inspect tables and columns.
3. Clean and validate the data.
4. Perform EDA.
5. Identify important business patterns.
6. Select a branch for forecasting.
7. Generate and evaluate the 7-day forecast.
8. Update the final report with dataset-supported findings.
